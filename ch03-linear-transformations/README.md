# 第3章 線形変換

## 概要

行列がベクトルを別のベクトルへ移す線形変換を表すことを理解し、表現行列、合成変換、逆変換、対称移動、回転を扱います。

## 学習目標

- [ ] 行列で表された線形変換による点の像を求められる
- [ ] 基底ベクトルの像から表現行列を作れる
- [ ] 合成変換と逆変換を表す行列を求められる
- [ ] 平面上の対称移動と回転の行列を求められる

## モデルコアカリキュラム

| MCC コード | 到達目標 |
|------------|----------|
| LA-T-01 | 行列が線形変換を表すことを理解し、線形変換された点の座標を求めることができる。 |
| LA-T-02 | 合成変換及び逆変換を表す行列を求めることができる。 |
| LA-T-03 | 対称移動や平面内の回転が線形変換であることを理解し、線形変換を表す行列を求めることができる。 |
