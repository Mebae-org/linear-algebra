# 第1章 ベクトルと空間図形

## 概要

ベクトルの成分表示と基本演算を身につけ、内積を使って長さ・角度・平行・垂直を調べます。さらに、空間内の直線・平面・球をベクトルから方程式で表します。

## 学習目標

この章を終えると、次のことができるようになります。

- [ ] ベクトルの和、差、実数倍、成分、大きさを計算できる
- [ ] 内積と2ベクトルのなす角を求められる
- [ ] ベクトルの平行・垂直を判定できる
- [ ] 与えられた条件から空間内の直線・平面・球の方程式を立てられる
