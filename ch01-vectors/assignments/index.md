# 課題 01 - ベクトルと空間図形

- 対象範囲: [`../docs/index.md`](../docs/index.md) 全節
- 配点: 20点（各問4点）
- 採点方法: GitHub Actions による自動採点
- 提出方法: [課題01 提出フォーム（Issue）](https://github.com/Mebae-org/linear-algebra/issues/new?template=assignment-ch01.yml)

各問の解答は、単位・式・途中式を含めず、半角の整数1つだけを入力してください。不正解の場合は、新しい Issue を作成して再挑戦できます。

## 問1

$\boldsymbol{a}=(2,-1,3)$、$\boldsymbol{b}=(1,4,-2)$ のとき、$3\boldsymbol{a}-2\boldsymbol{b}$ の第1成分を求めてください。

## 問2

ベクトル $(2,-3,6)$ の大きさを求めてください。

## 問3

ベクトル $(1,2,-1)$ と $(3,0,2)$ の内積を求めてください。

## 問4

ベクトル $(1,-2,3)$ と $(k,-6,9)$ が平行になるとき、$k$ を求めてください。

## 問5

点 $(1,-1,2)$ を通り、法線ベクトルが $(2,1,-1)$ である平面を $2x+y-z=d$ と表すとき、$d$ を求めてください。
