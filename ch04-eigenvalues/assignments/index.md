# 課題 04 - 固有値と固有ベクトル

- 対象範囲: [`../docs/index.md`](../docs/index.md) 4.1から4.5
- 配点: 20点（各問4点）
- 採点方法: GitHub Actions による自動採点
- 提出方法: [課題04 提出フォーム（Issue）](https://github.com/Mebae-org/linear-algebra/issues/new?template=assignment-ch04.yml)

各問の解答は、単位・式・途中式を含めず、半角の整数1つだけを入力してください。不正解の場合は、新しい Issue を作成して再挑戦できます。

## 問1

$A=\begin{pmatrix}4&1\\2&3\end{pmatrix}$ の大きい方の固有値を求めてください。

## 問2

問1の行列の小さい方の固有値に属する固有ベクトルを $(1,y)^T$ とするとき、$y$ を求めてください。

## 問3

$B=\begin{pmatrix}2&1\\1&2\end{pmatrix}$ の固有値の和を求めてください。

## 問4

$C=\begin{pmatrix}1&1\\0&1\end{pmatrix}$ の固有値 $1$ に対する固有空間の次元を求めてください。

## 問5

$B=\begin{pmatrix}2&1\\1&2\end{pmatrix}$ の $B^3$ の第1行第2列成分を求めてください。
