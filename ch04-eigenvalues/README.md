# 第4章 固有値と固有ベクトル

## 概要

線形変換によって向きが変わらない特別なベクトルを調べ、固有値・固有ベクトルを計算します。発展として対角化による行列の累乗も扱います。

## 学習目標

- [ ] 特性方程式から行列の固有値を求められる
- [ ] 各固有値に対応する固有ベクトルを求められる
- [ ] 計算した固有値・固有ベクトルを定義式で確認できる
- [ ] 対角化できる場合に行列の累乗を計算できる
