# 第2章 行列と連立一次方程式

## 概要

行列の基本演算、正則性、逆行列、行列式を学び、それらを使って連立一次方程式を解きます。

## 学習目標

- [ ] 行列の和、差、実数倍、積を計算できる
- [ ] 正方行列の正則性を判定し、逆行列を求められる
- [ ] 行列式の性質を利用して値を計算できる
- [ ] 掃き出し法や逆行列を使って連立一次方程式を解ける

## モデルコアカリキュラム

| MCC コード | 到達目標 |
|------------|----------|
| LA-M-01 | 行列の和、差、実数倍、及び積の計算ができる。 |
| LA-M-02 | 行列の正則性を判定し、逆行列を求めることができる。 |
| LA-M-03 | 行列式の性質を理解し、行列式の値の計算ができる。 |
| LA-M-04 | 行列を利用して連立一次方程式を解くことができる。 |
